# Bill of materials

`ASMR2026-BOM.xlsx` is the hardware team's working BOM workbook provided on 18 November 2026. It contains the main BOM, actuator-specific sheets, and purchase tracking sheets.

The workbook is added as supplied. Check quantities, prices, purchase status, and supplier links against the current build before ordering. Hardware files and related documentation in this repository are covered by the [CC BY-SA 4.0 license](../../LICENSES/CC-BY-SA-4.0.txt).
