# MotorTestGUI

실물 로봇과 시뮬레이션(MuJoCo)이 같게 세팅됐는지 확인하는 프로그램입니다. 관절 방향과 영점을 맞추고, 모터를 조금씩 움직여 볼 수 있습니다.

- 왼쪽 3D: 실물 로봇. CAN으로 읽은 엔코더 값을 관절 각도로 바꿔 수업 모델(Robot Model v1)에 입힌 그림입니다.
- 가운데 3D: 시뮬레이션. 몸통을 고정한 같은 모델이 실물과 같은 목표 궤적을 받아 움직입니다.
- 오른쪽 패널: 관절 선택, 실시간 그래프(각도·속도·토크), 명령 탭(토크 켜기·힘 풀기, 상대·절대 이동), 영점·방향 설정 탭.
- 위쪽 줄: CAN 연결 상태(CANable 1~2개), 노드 12개 상태, Vbus, 버스 점유율, 빨간 **모두 힘 풀기 (Esc)** 버튼.

이 노트북(Windows, PowerShell) 기준으로 썼습니다.

## 3. 실물 로봇 연결

1. 로봇을 받침대에 매답니다.
2. **다리를 곧게 편 자세(시뮬 0° 자세)** 로 두고 드라이버 전원을 켭니다. 이유는 6절 "24° 문제"에 있습니다.
3. CANable을 노트북 USB에 꽂습니다. 두 개면 둘 다 꽂습니다.
4. 프로그램 위쪽에서 고릅니다.
   - **CAN 어댑터**: `slcan (CANable 출고 펌웨어, COM)`
   - **포트 1·2**: CANable이 꽂힌 COM 포트. 목록에 "CANable"이라고 나오고, 안 보이면 ↻를 누릅니다.
     - CANable이 두 개면 포트 1과 포트 2에 하나씩 고릅니다. 처음 실행할 때는 찾은 순서대로 자동으로 들어갑니다.
     - 하나만 쓰면 포트 2는 **(사용 안 함)**으로 둡니다.
   - **속도**: `500 kbps` (두 버스 모두 같은 속도)
5. **연결**을 누릅니다. 위쪽 노드 표시가 초록(힘 풀림)이 되는지 봅니다. 회색은 응답 없음입니다.

연결해도 토크는 켜지지 않습니다. 프로그램은 값을 읽는 요청만 보냅니다.
- 연결할 때 이미 토크가 켜진 보드가 있으면(다른 스크립트가 켜 둔 채 끝난 경우 등) 프로그램이 바로 힘을 풀고 경고를 띄웁니다.
- 토크는 관절을 고르고 **토크 켜기**를 눌렀을 때 그 관절에만 켜집니다.

### CANable 두 개 (CAN 버스 2개)

왼다리와 오른다리가 서로 다른 CAN 버스에 있고 CANable이 버스마다 하나씩이면, 둘을 **동시에** 연결해서 12개 관절을 한 화면에서 다룹니다.

- **포트 1이 왼다리일 필요는 없습니다.** 어느 노드가 어느 버스에 있는지는 연결하면 그 노드의 응답이 들어오는 버스를 보고 자동으로 알아냅니다. 그 노드에 보내는 명령은 그 버스로만 갑니다.
- 노드 번호는 두 다리 사이에 겹치지 않아야 합니다. 지금은 왼다리 1·3·5·7·11·13, 오른다리 2·4·6·8·12·14입니다.
- 어느 COM 포트가 어느 다리인지는 화면에서 보입니다.
  - 관절 표의 **node** 칸: "7 · 버스1"
  - 위쪽 노드 버튼에 마우스를 올리면: "버스 1 (COM5)"
  - COM 번호는 USB 포트를 바꿔 꽂으면 달라질 수 있지만, 자동으로 다시 알아내니 신경 쓰지 않아도 됩니다.
- 위쪽 통계 줄에 버스별 점유율과 노드 수가 나옵니다. 예: "버스1 16% (6개) · 버스2 15% (6개)". 한 버스에 12개를 다 물렸을 때보다 버스당 부하가 절반쯤입니다.
- 응답이 끊긴 노드를 찾는 요청과 **모두 힘 풀기(Esc)** 는 두 버스 모두에 보냅니다.

하드웨어 확인:
- 버스마다 양 끝(CANable 쪽과 그 버스의 마지막 드라이버 쪽)에 120 Ω 종단이 있어야 합니다.
- CANable 두 개를 **같은 버스**에 물리면 안 됩니다. 그러면 같은 노드 응답이 두 버스에서 다 들어오고, 프로그램이 "양쪽에서 들어옵니다" 경고를 띄웁니다.

CANable이 하나뿐이라 한 다리씩 작업할 때는, 한 다리를 끝내고 **설정 저장** → **끊기** → 다른 다리 버스에 꽂고 **연결**합니다. 다시 연결할 때는 그 다리를 곧게 편 자세로 둡니다. 연결할 때마다 24° 단위를 다시 고르기 때문입니다 (6절).

## 4. 방향 확인

관절 각도는 `방향 × (모터 위치 − 영점) ÷ 15`로 계산합니다. 방향이 틀리면 화면에서는 명령을 잘 따르는 것처럼 보이다가 실물은 기구 끝에 부딪힙니다. 영점보다 먼저, 또는 함께 확인합니다.

1. 다리를 곧게 펴고, **영점·방향 설정** 탭에서 **모든 관절 지금 = 0°**를 누릅니다. 대략적인 영점입니다.
2. 오른쪽 위에서 관절을 고릅니다.
3. **명령** 탭에서 **토크 켜기**를 누르고 **+5°**를 누릅니다.
4. 3D 화면에서 확인합니다.
   - 노란 화살표가 회전축, 노란 호가 + 방향입니다 (오른손 법칙: 엄지 = 화살표, 손가락이 감기는 쪽 = +).
   - 실물이 왼쪽 그림과 같은 쪽으로 움직였으면 방향이 맞습니다.
5. 반대로 움직였으면 **힘 풀기**를 누르고, **영점·방향 설정** 탭에서 방향을 **−1**로 바꿉니다. 0° 자세에서 영점을 잡았다면 영점은 다시 잡지 않아도 됩니다.
6. 토크 그래프의 실측(파랑)과 시뮬(청록) 부호가 반대면 **토크 부호(Iq)**를 바꿉니다. 그래프 표시에만 쓰이는 값입니다.
7. 관절마다 반복하고 **설정 저장**을 누릅니다.

## 5. 영점 설정

영점은 프로그램 설정 파일 `config/robot_config.json`에 저장됩니다 (드라이버에 저장하지 않음). 두 가지 방법이 있습니다.

### 방법 A: 지금 자세를 영점으로

- 다리를 곧게 편 자세에서 **모든 관절 지금 = 0°**를 누릅니다.
- 관절 하나만 하려면 **지금 자세 =** 칸에 각도를 넣고 **영점 정하기**를 누릅니다.
- 정확도는 손으로 자세를 얼마나 맞췄느냐에 달렸습니다 (보통 1~2°).

### 방법 B: 범위 훑기 (기구 끝 기준, 더 정확)

**영점·방향 설정** 탭의 **범위 훑기** 줄에서 합니다.

1. 모든 관절의 힘을 풀고 **시작**을 누릅니다. 토크가 켜진 관절이 있으면 시작되지 않습니다.
2. 관절마다 손으로 **양쪽 기구 끝까지** 천천히 돌리고, 끝에서 가볍게 한 번씩 댑니다.
   - 관절 표 알림 칸에 "기록 폭 / 기구 폭"이 나옵니다.
   - 돌리는 관절 말고 다른 관절은 곧게 펴 둡니다.
   - 빨리 돌리면 모터가 발전기처럼 전압을 만듭니다. 특히 12 V 파워서플라이를 쓸 때는 천천히 돌립니다.
3. 다리를 곧게 펴 두고 **끝 → 영점 계산**을 누릅니다.
4. 결과 창을 봅니다.
   - **지금 각도**가 0° 근처인지 확인합니다. 무릎이 −140°처럼 크게 다르면 방향이 반대입니다.
   - 체크된 관절만 적용됩니다. 기록 폭과 기구 폭이 3° 안으로 맞는 관절이 기본으로 체크됩니다.
5. **체크한 관절에 영점 적용**을 누르고, **설정 저장**을 누릅니다.

관절별로 쓸 수 있는 정도가 다릅니다. 기구 끝 각도는 수업 모델 메쉬 충돌 검사 결과입니다.

| 관절 | 기구 끝 | 범위 훑기 |
|---|---|---|
| knee, ankle pitch, ankle roll | 시뮬 범위 끝과 같음 | 양 끝 평균으로 계산 (가장 정확) |
| hip pitch | 시뮬 범위보다 19~24° 바깥 | 양 끝 평균으로 계산 |
| hip yaw | 한쪽만 (몸통 프레임에 닿음) | 기본 체크 안 함. 그 끝까지 댔다면 직접 체크 |
| hip roll | 없음 | 쓸 수 없음 → 방법 A |

- hip yaw는 두 다리를 곧게 두면 반대쪽 발목에 먼저 닿습니다. 반대쪽 다리를 벌려 두고 돌립니다.
- 실물의 기구 끝이 다르게 나오면 `config/robot_config.json`에서 관절마다 `stop_lo_deg` / `stop_hi_deg`를 고칩니다.

## 6. 다음에 켤 때 (24° 문제)

코스 펌웨어는 전원을 켤 때 모터 한 바퀴 안의 위치만 압니다. 감속비가 15라서 모터 한 바퀴는 관절 24°입니다. 그래서 프로그램은 **처음 보드를 볼 때(연결할 때, 또는 연결된 상태에서 드라이버를 켤 때) 관절이 기준 자세(기본 0°) ±12° 안에 있다고 보고** 24° 칸을 고릅니다.

- 저장한 영점은 계속 유효합니다. 다시 잡을 필요가 없습니다. 모터나 링크를 분해·재조립했을 때만 다시 잡습니다.
- 매번 **다리를 곧게 편 자세에서 연결**하면 각도가 바로 맞습니다.
- 어떤 관절이 정확히 24°쯤 틀려 보이면, 그 관절을 0° 근처로 옮기고 **각도 다시 맞추기**(전체는 **모두 다시 맞추기**)를 누릅니다.
- 항상 다른 자세에서 켠다면 **전원 켤 때 기준 자세** 값을 그 자세 각도로 바꿉니다.

## 7. 안전

- **Esc** 또는 빨간 **모두 힘 풀기** 버튼은 모든 노드를 IDLE로 둡니다. 진짜 비상 정지는 전원 스위치로 합니다.
- 한 번 명령은 **한 번 최대**(기본 30°)까지만 움직입니다. 영점이 있으면 목표를 시뮬 관절 범위에서 2° 안쪽으로 자릅니다.
- **보호 정지**: 목표와 실측 차이가 10°를 넘는 상태가 0.5초 넘게 가거나, 전류가 8 A를 넘는 상태가 1초 넘게 가면 그 관절만 IDLE이 됩니다. 방향이 틀린 관절이 기구 끝을 밀어붙이는 것을 막기 위한 장치입니다.
- 창을 닫을 때 토크가 켜진 관절이 있으면 힘을 풀지 묻습니다. "끊기"를 누르면 모두 힘을 풉니다.

## 8. 문제 해결

| 증상 | 확인 |
|---|---|
| 연결 실패 | COM 포트가 맞는지, 다른 프로그램(odrivetool, 시리얼 터미널, BasicTest 스크립트)이 그 포트를 잡고 있지 않은지. 메시지에 "포트 1"/"포트 2" 중 어느 쪽이 실패했는지 나옴 |
| "포트 1과 포트 2가 같습니다" | 포트 2를 두 번째 CANable로 바꾸거나 **(사용 안 함)**으로 |
| 노드 몇 개만 회색(없음) | 그 드라이버 전원, CAN 배선, node ID |
| 한쪽 다리 노드가 전부 회색 | 그 다리 버스의 CANable을 포트 2에 안 넣었거나(**사용 안 함**), 그 버스의 전원·배선·종단 문제 |
| "양쪽 버스에서 들어옵니다" 경고 | CANable 두 개가 같은 버스에 물림, 또는 두 버스에 같은 node ID 보드가 있음 (3절) |
| 각도가 24°쯤 틀림 | 6절 "각도 다시 맞추기" |
| 범위 훑기 "폭 불일치" | 끝까지 안 갔거나 다른 링크에 먼저 닿음. 계속 같으면 실물 기구 끝이 모델과 다른 것이니 `stop_lo_deg`/`stop_hi_deg` 확인 |
| 위쪽 "폴링 Hz"가 낮음 | `config/robot_config.json`의 `poll_hz`를 낮춤 (기본 50) |
| 설정이 사라짐 | **설정 저장**(Ctrl+S)을 눌러야 파일에 남음. 종료할 때 저장 안 했으면 물어봄 |
